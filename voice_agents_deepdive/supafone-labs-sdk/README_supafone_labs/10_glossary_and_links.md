# 10 · Glossary & Links

## Glossary

| Term | Meaning |
| --- | --- |
| **Sidecar Oracle** | The core idea: a second, slower LLM running *beside* the call (off the latency hot path) that issues silent corrections. |
| **Supafone Supervisor** | The productized sidecar. Observes calls, whispers bounded directives, scores/QA's calls. On by default for hosted agents. |
| **supercharge()** | SDK entry point that wraps an agent you already run and adds supervision. |
| **Agent Factory** | The "provision a complete agent" path — number, voice, stages, tools, artifacts, supervision from one key. |
| **Canonical event algebra** | A normalized event vocabulary all provider adapters `parse` raw events into. |
| **Adapter** | Per-provider code with two pure functions: `parse: Raw → E*` and `compile: D × Σ → A`. 14 audited. |
| **Σ (runtime state)** | Deterministic, model-free, replayable state: transcript + language tags + tool history + truth sub-state. |
| **Truth state / truth sub-state** | Whether a booking/transfer/send/CRM action was *actually verified* by a tool result — separate from what the model *said*. |
| **Standing directive** | A persistent, versioned coaching preamble on the supervisor's own channel, injected at call start. Optimized offline; never touches the operator's base prompt. |
| **Mode A injection** | Native silent event on a speech-to-speech model (adds context without triggering speech). |
| **Mode B injection** | Supafone owns the pipeline LLM and splices a `system`/`developer` message into the prompt. |
| **Degrade-safety** | Supervisor failure composes with the live call as a no-op. It cannot lengthen, alter, or end the call. |
| **SSR grading** | Five-level nominal judging (poorly/ok/good/great/perfectly) mapped deterministically to score distributions. New in v1.1. |
| **OPRO** | Offline, score-driven prompt optimization technique used to improve the standing directive. |
| **BYOK** | Bring Your Own Keys — connect your own telephony/TTS/STT/supervisor-LLM providers. |
| **Whisper** | A single silent directive delivered to the live agent as context (never spoken to the caller). |
| **Transcript authority** | The single STT source chosen per call (provider-native stream, Deepgram multilingual tap, or host narrowband tap). |
| **Call stages** | The multi-stage conversation flow (intake → qualification → scheduling → confirmation) generated by the planner. |
| **sl_ key** | The one Labs key (`sl_live_...`) that authenticates both `api.labs.supafone.ai` and `api.supafone.ai`. |

## Framework coverage summary (14 runtimes)

- **Native control:** Supafone Agent Factory, Ultravox, Vapi, OpenAI Realtime, Grok Voice Agent, Gemini Live, ElevenLabs Agents, Deepgram Voice Agent, Inworld Realtime
- **Developer-owned context:** Retell (custom LLM), LiveKit Agents, Pipecat
- **Observation / explicit hook only:** Bland (observe-only), Cartesia Line (host hook)
- **Extension path:** `GenericWebhookAdapter` for proprietary systems

## Telephony providers

Twilio · Telnyx · Plivo · SignalWire · SIP / custom trunks · (media streams: Twilio,
Jambonz, FreeSWITCH, Asterisk, Vonage referenced on the marketing site)

## TTS / STT providers

- **TTS:** Cartesia, ElevenLabs, Inworld, Deepgram, custom
- **STT:** Deepgram (`nova-3` multilingual tap; `nova-2-phonecall` narrowband default) or provider-native transcript streams
